# Nifty 100 Data Foundation & Analytics Dashboard

A financial analytics platform for analysing Nifty 100 companies using historical financial statements, financial ratios, valuation metrics, peer comparisons, sector analytics, and interactive Streamlit visualisations.

The project contains financial data for 92 companies and provides an 8-screen Streamlit dashboard for company-level and market-level analysis.

---

## Dashboard

The Streamlit dashboard provides interactive analysis of Nifty 100 companies using the project's SQLite database.

### Run the Dashboard

From the project root directory:

```bash
streamlit run src/dashboard/app.py
